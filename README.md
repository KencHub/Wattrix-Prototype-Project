# ⚡ Wattrix — Smart Energy Tracking

> Making shared power usage **transparent, fair, and efficient** for homes, offices, and communities.

---

## 📌 Overview

Wattrix is a smart energy monitoring prototype that enables individuals, households, and organizations to track electricity consumption in real time, split costs fairly among users, and manage connected devices — all from a single, intuitive interface.

Whether you're splitting a utility bill with roommates, managing power consumption across office workstations, or overseeing energy usage in a shared community space, Wattrix gives every stakeholder a clear, data-driven view of their contribution.

🔗 **Live Demo:** [https://wattrix-prototype-project.vercel.app](https://wattrix-prototype-project.vercel.app)

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 📊 **Dashboard** | At-a-glance summary of total energy consumed and total cost incurred |
| ⚡ **Live Data** | Real-time power usage chart updated continuously |
| 📅 **Usage History** | Tabular log of energy usage per user, device, time slot, and cost |
| 🧾 **Receipt Generation** | Generate per-user billing receipts on demand |
| 💰 **Shared Expenses** | View and split energy costs fairly across all users |
| 🔔 **Alerts** | Configure and toggle user-specific consumption alerts; report anomalies |
| 👤 **User Details** | Inspect individual user profiles and their usage metadata |
| 🔌 **Device Details** | View specifications and usage data for registered devices |
| 🔧 **Device Status** | Toggle device power state, view history, download data logs |
| 🙍 **Profile** | Manage your personal account settings |

---

## 🖥️ How It Works

1. **Sign In** — Authenticate with your credentials to access the Wattrix dashboard.
2. **Monitor Live Usage** — The app polls real-time power data, displaying it as an interactive chart.
3. **Review History** — Browse a time-stamped log that breaks down energy (kWh), power (W), and cost ($) by user and device.
4. **Generate Receipts** — Select a user and print a detailed billing receipt for any period.
5. **Split Expenses** — Use the shared expense panel to automatically calculate each user's fair share of the bill.
6. **Manage Devices** — Toggle devices on/off, clear device history, or download raw data for external analysis.
7. **Set Alerts** — Assign usage threshold alerts per user and get notified when limits are approached or exceeded.

## 📱 App Interface

Wattrix ships with a **mobile-first app view** (simulated at 9:41, the classic demo timestamp) alongside the full desktop experience. The mobile UI mirrors the full feature set through a hamburger-menu navigation system, making it accessible on any screen size.

## 🧪 Interactive Simulation

Don't have live hardware? Use the built-in **Simu Wattrix** feature — an interactive simulation that generates realistic energy data so you can explore all features without connecting any actual devices. Just click **Run Simulation** on the homepage.

---

## 📊 Data Matrix

The **Data Matrix** section provides a charted view of sample power usage data across a configurable date/time range. It is designed to give administrators a high-level picture of consumption patterns over time.

> 📌 *Tip: Rotate your device to landscape mode for the full chart experience on mobile.*
